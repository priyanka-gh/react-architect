# Changelog

## 0.1.0

First release.

- **Create React Project:** React, TypeScript and Vite with a feature-based layout, optional React Router, Vitest and React Testing Library, ESLint and Prettier. Progress can be cancelled, a half-made folder can be deleted, and a failed install can be retried.
- **Generate Component, Hook and Feature** from the Command Palette or the Explorer's folder menu, with a preview before writing, overwrite or skip for existing files, and optional exports from a feature's `index.ts`.
- **Set Up Existing Project:** suggests a `react-architect.json` based on the project's folders and tools.
- Autocomplete and checking for `react-architect.json`.
